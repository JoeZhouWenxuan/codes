## 二、第 136 题详解 — 只出现一次的数字

### 题目描述
给定一个数组，其中除了一个元素只出现一次外，其余元素都出现两次，找出这个只出现一次的元素。

### 示例
- `nums = [2,2,1]` -> `1`
- `nums = [4,1,2,1,2]` -> `4`

### 核心思路：利用异或的消去性质

异或满足：
- `a ^ a = 0`
- `a ^ 0 = a`
- 异或满足交换律和结合律

因此把数组里所有数全部异或起来：
- 成对出现的数字都会抵消
- 最后剩下的就是只出现一次的那个数

#### 代码
```python
class Solution:
    def singleNumber(self, nums):
        ans = 0
        for num in nums:
            ans ^= num
        return ans
```

#### 复杂度
- 时间复杂度：**O(n)**
- 空间复杂度：**O(1)**

## 三、第 338 题详解 — 比特位计数

### 题目描述
给定整数 `n`，返回 `0` 到 `n` 每个数字二进制中 `1` 的个数。

### 示例
- `n = 2` -> `[0,1,1]`
- `n = 5` -> `[0,1,1,2,1,2]`

### 核心思路：利用右移和最低位

对于任意整数 `i`：
- `i >> 1` 相当于去掉二进制最后一位
- `i & 1` 表示最后一位是不是 `1`

所以有经典转移：

`bits[i] = bits[i >> 1] + (i & 1)`

#### 代码
```python
class Solution:
    def countBits(self, n):
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = dp[i >> 1] + (i & 1)
        return dp
```

#### 复杂度
- 时间复杂度：**O(n)**
- 空间复杂度：**O(n)**

## 四、第 461 题详解 — 汉明距离

### 题目描述
给你两个整数 `x` 和 `y`，返回它们二进制表示中不同位的个数。

### 示例
- `x = 1, y = 4` -> `2`
- `x = 3, y = 1` -> `1`

### 核心思路：先异或，再统计 1 的个数

如果两个数在某一位不同，那么异或结果这一位就是 `1`。

所以步骤很直接：
1. 先计算 `x ^ y`
2. 再统计结果中有多少个 `1`

#### 代码
```python
class Solution:
    def hammingDistance(self, x, y):
        diff = x ^ y
        count = 0

        while diff:
            diff &= diff - 1
            count += 1

        return count
```

#### 复杂度
- 时间复杂度：**O(1)** 或按位数记作 **O(log n)**
- 空间复杂度：**O(1)**
