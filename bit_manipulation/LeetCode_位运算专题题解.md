## 二、第 461 题详解 — 汉明距离

### 题目描述
给你两个整数 `x` 和 `y`，返回它们二进制表示中不同位的个数。

### 示例
- `x = 1, y = 4` -> `2`
- `x = 3, y = 1` -> `1`

### 核心思路：先异或，再统计 1 的个数

如果两个数在某一位不同，那么异或结果这一位就是 `1`。

所以步骤很直接：
1. 先计算 `x ^ y`
2. 再统计结果中有多少个 `1`

#### 代码
```python
class Solution:
    def hammingDistance(self, x, y):
        diff = x ^ y
        count = 0

        while diff:
            diff &= diff - 1
            count += 1

        return count
```

#### 复杂度
- 时间复杂度：**O(1)** 或按位数记作 **O(log n)**
- 空间复杂度：**O(1)**
