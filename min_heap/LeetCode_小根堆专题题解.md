## 二、小根堆适合什么题

### 1. 维护前 K 个元素
- `215`
- `347`
- `703`

思路是：
- 用大小为 `k` 的小根堆
- 堆顶始终是“当前前 k 个元素里最小的那个”
- 新元素更优时再替换堆顶

---

### 2. 合并多个有序流
- `23`

思路是：
- 把每个有序链表的当前最小节点放进堆
- 每次弹出全局最小值，再补入该链表的下一个节点

---

### 3. 按最小代价逐步扩展
- `373`

思路是：
- 先把最小候选对放进堆
- 每次弹出当前最小组合，再扩展它的下一个候选

---

## 四、小根堆核心模板

### 固定大小维护 Top K

```python
heap = []
for x in nums:
    heappush(heap, x)
    if len(heap) > k:
        heappop(heap)
```

### 多路归并

```python
先把每一路的第一个元素放入堆
循环弹出堆顶
把它所在那一路的下一个元素再放入堆
```
