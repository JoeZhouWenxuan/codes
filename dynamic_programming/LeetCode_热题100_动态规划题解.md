## 二、常见 DP 类型

### 1. 线性 DP
- `53. 最大子数组和`
- `70. 爬楼梯`
- `198. 打家劫舍`
- `309. 买卖股票的最佳时机含冷冻期`

这类题通常满足：
- 当前状态只依赖前一个或前几个状态
- 可以把“到当前位置的最优值”写成状态转移

---

### 2. 网格 DP
- `62. 不同路径`
- `64. 最小路径和`

特点是状态往往写成：

`dp[i][j]`

表示走到网格位置 `(i, j)` 时的答案。

---

### 3. 背包 DP
- `279. 完全平方数`
- `322. 零钱兑换`
- `416. 分割等和子集`
- `494. 目标和`

核心是考虑：
- 容量是多少
- 每个物品能否重复使用
- 状态转移方向是正序还是倒序

---

### 4. 子序列 DP
- `300. 最长递增子序列`
- `1143. 最长公共子序列`

这类题通常需要比较多个位置之间的关系，状态定义相对更细。

---

### 5. 匹配型 / 字符串 DP
- `10. 正则表达式匹配`
- `72. 编辑距离`

特点是：
- `dp[i][j]` 表示前缀是否匹配
- 常常需要针对特殊字符分类讨论
- `*` 这类字符通常有“匹配 0 次”和“匹配多次”两种转移

编辑距离类题则常见三种操作转移：
- 插入
- 删除
- 替换
---

### 6. 区间 DP
- `312. 戳气球`

特点是：
- `dp[left][right]` 往往表示一个区间内部的最优答案
- 常常需要枚举“最后一步”或“最后一个划分点”

---

### 7. 树形 DP
- `337. 打家劫舍 III`

特点是：
- 每个节点返回多个状态
- 父节点根据左右子树状态继续转移

## 四、DP 核心模板

动态规划通常按这四步思考：

1. 定义状态  
   `dp[i]` 或 `dp[i][j]` 表示什么

2. 写转移方程  
   当前答案如何由之前状态推出

3. 确定初始化  
   最小子问题的答案是什么

4. 确定遍历顺序  
   先算谁，后算谁，才能保证依赖项已知
